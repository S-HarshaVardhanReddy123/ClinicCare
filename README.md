# ClinicCare

ClinicCare is a full-stack healthcare platform for discovering hospitals,
finding doctors, booking appointments, receiving prescriptions,
managing payments, and providing patient feedback.

## Project Goals

ClinicCare will provide:

- User registration and login
- Location-based hospital search
- Hospital ratings and reviews
- Hospital facility information
- Doctor profiles
- Doctor specialization and qualifications
- Doctor availability
- Appointment booking
- Doctor appointment management
- Email and SMS notifications
- Digital prescriptions
- Payment management
- Patient feedback
- Admin management
